# Charles Neenwi — Frontend Engineer Portfolio

A modern, responsive portfolio website built with React. Features a dark/light theme toggle, smooth scroll animations, and a resume download button.

🌐 **Live Site:** [charlesneenwi.vercel.app](https://charlesneenwi.vercel.app) ← update this after deploying

---

## About

This is my personal portfolio showcasing my skills, projects, and experience as a Frontend Engineer. I'm an ALX-certified React developer based in Port Harcourt, Nigeria.

---

## Features

- Dark / Light mode toggle
- Smooth scroll-triggered animations
- Resume PDF download
- Fully responsive (mobile, tablet, desktop)
- Sections: Hero, About, Skills, Projects, Contact

---

## Tech Stack

- **React** — UI framework
- **CSS-in-JS** — inline styles with dynamic theming
- **Google Fonts** — Bebas Neue + DM Sans
- **Vercel** — deployment

## Getting Started

```bash
# Clone the repo
git clone https://github.com/charlesneenwi/portfolio.git

# Navigate into the project
cd portfolio

# Install dependencies
npm install

# Start the development server
npm start
```

---

## Deployment

This project is deployed on [Vercel](https://vercel.com). Every push to the `main` branch triggers an automatic redeployment.
